【アップデート情報】

Ver.1.0

リリース開始
PNG、GIFとして画像を並べ、軽いアニメーションを作成するソフトとして制作が開始。

対応ファイルは、PNG等基本的な画像ファイル、GIFアニメーション。透過ファイルも読み込み可能。透過GIFを重ねることも可能。
ソフト自体は透過GIFの書き出しに対応し、基本機能は実装完了。

Ver2.0への方針として、アニメーションの拡充とテキストへの対応を行う。ソフト内でテキストを挿入し、コメントを付けたりテキストの編集をできるようにする。また、テキストデータでの書き出しに関して、AIによるフレームの生成が容易になるようにしたい。AIで軽く生成し、それを人間の手で調整・イラストの張替えを行い、作成することを目的とする。
